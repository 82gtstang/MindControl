# Townsperson source

Townsperson.fbx uses the MakeHuman base mesh for the modeled head and hands.
The MakeHuman base mesh is released under CC0 1.0 Universal.
https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md

The robe, hood, boots, and accessories were modeled for MindControl. All
visible surfaces are modeled in 3D and use solid materials without projected
character images.
