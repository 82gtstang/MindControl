# Character asset integration

The Godot runtime supports `hero.glb` and `enemy.glb` in this folder. These assets are not currently committed.

Candidate licensed models: KayKit Adventurers (CC0), Knight and Rogue_Hooded. Source: https://github.com/KayKit-Game-Assets/KayKit-Character-Pack-Adventures-1.0 . The characters are stylized rather than photorealistic. Their use requires importing actual model files before building.

For truly realistic dark fantasy characters, obtain properly licensed high-detail rigged GLB models with PBR materials and compatible animations, then replace these two files. Keep license records with the project.
