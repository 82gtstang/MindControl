# Mind Control — Ashenvale 3D

An original third-person fantasy RPG prototype built in **Godot 4**, optimized toward Android with the GL Compatibility renderer.

## What works
- Fully 3D third-person camera, mobile drag-to-look and left-side virtual movement.
- Procedurally constructed forest, stone road, temples, ruins, moonpool and flickering torches.
- Armored knight with a sword attack animation; shadow enemies, health, gold and healing.
- Three discoverable sigils and a quest completion message.
- Desktop keyboard arrows/WASD (ui actions) and right-mouse camera rotation.

## Run locally
Open `godot/project.godot` in Godot 4.3+ and press F6/F5.

## Android build
Install Godot Android export templates and Android SDK; export as Android APK. This folder is a **new Godot project**; the old `app/` Kotlin project remains in the repository but is not the 3D game.

## Art direction
This is a working **3D greybox/procedural prototype**, not photorealistic game art. Cinematic character models, animations, PBR textures, ambient audio and detailed authored levels require additional licensed assets and production work.
